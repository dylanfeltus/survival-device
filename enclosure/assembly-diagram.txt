╔════════════════════════════════════════════════════════════════════════════╗
║                          ASSEMBLY SEQUENCE                                 ║
╚════════════════════════════════════════════════════════════════════════════╝

    STEP 1: Prepare Bottom Shell
            ↓
            Install 4× M3 heat-set inserts in corner bosses
            Use soldering iron at 220°C (PLA) or 250°C (PETG)

    STEP 2: Battery
            ↓
            Lay the LiPo pouch cell in its padded bay (no clamping/puncture risk)

    STEP 3: Mount SeenGreat UPS HAT (B)
            ↓
            Power switch OFF
            Plug the pouch cell into the 2-pin connector (check polarity)
            (Solar) set MPPT DIP switch to panel Vmp — only ONE position ON

    STEP 4: Install Orange Pi Zero 2W
            ↓
            Header soldered/press-fit first
            Seat on the HAT's pogo pins, fasten standoffs evenly
            Switch HAT ON → board boots on battery; `i2cdetect` shows 0x43

    STEP 5: Wire Displays + Encoder (jumper wires, docs/wiring.md)
            ↓
            2.8" TFT on SPI1 CS0, round TFT on SPI1 CS1, encoder on PI12/PI2/PI16
            All modules powered from 3.3V; TFT SDO/MISO left unconnected

    STEP 6: Mount Panels + Encoder in Top Shell
            ↓
            TFT behind the main window, round TFT behind its window
            Thread encoder shaft, secure body, attach knob

    STEP 7: Close Enclosure
            ↓
            Route wires carefully (avoid pinching)
            Align top shell with alignment pins
            Insert 4× M3 screws and tighten diagonally

    STEP 8: Final Testing
            ↓
            USB-C into the HAT; unplug and confirm it stays up on battery
            Verify TFT, round display, encoder, battery % in the UI
            Thermal test (30 minutes runtime)


╔════════════════════════════════════════════════════════════════════════════╗
║                         TROUBLESHOOTING GUIDE                              ║
╚════════════════════════════════════════════════════════════════════════════╝

    ISSUE: Case won't close
    FIX:   ├─ Check for wire pinching at shell interface
           ├─ Verify all components are seated properly
           └─ Check for warped print (reheat and flatten if needed)

    ISSUE: LCD doesn't align with window
    FIX:   ├─ Loosen PCB mounting screws and adjust position
           ├─ Add shims under PCB standoffs
           └─ Modify .scad file `lcd_active_width/height` variables

    ISSUE: Ports not accessible
    FIX:   ├─ Verify Orange Pi is oriented correctly (180° check)
           ├─ File/enlarge port cutouts if needed
           └─ Check PCB standoff heights

    ISSUE: Overheating
    FIX:   ├─ Verify ventilation slots are clear
           ├─ Add heatsink to Orange Pi SoC chip
           └─ Reduce CPU governor to powersave mode

    ISSUE: Screws won't tighten (stripped threads)
    FIX:   ├─ Use heat-set inserts (essential for reusability)
           ├─ Don't overtighten — plastic has limits
           └─ If stripped, fill hole with epoxy and re-drill

╚════════════════════════════════════════════════════════════════════════════╝

    ┌─────────────────────────────────────────────────────────────┐
    │  "Built like a tool, not a toy."                            │
    │                                                              │
    │  This enclosure prioritizes:                                │
    │  • Repairability (screws, not glue)                        │
    │  • Durability (thick walls, rounded edges)                 │
    │  • Field-serviceable (heat-set inserts, modular)           │
    │  • Functional aesthetic (visible structure, tactical vibe) │
    │                                                              │
    │  It does NOT prioritize:                                    │
    │  • Minimal size (survival device, not a phone)             │
    │  • Sleek appearance (form follows function)                │
    │  • Waterproofing out-of-box (achievable with mods)         │
